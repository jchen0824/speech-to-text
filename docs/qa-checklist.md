# QA Checklist

- [ ] Mic permission prompt appears and recording starts after approval.
- [ ] Start/Stop toggles listening state and UI chip reflects status.
- [ ] Interim text shows while speaking; finalized lines append with timestamps.
- [ ] Autosave writes to the selected file every 30 seconds.
- [ ] Autosave toast appears briefly after each save and auto-dismisses.
- [ ] Copy All writes the full transcript to clipboard.
- [ ] Clear empties the transcript without deleting file contents.
- [ ] Change file lets the user pick a new output file.
